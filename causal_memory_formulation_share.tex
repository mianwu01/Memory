\section{My understanding of the project}\label{sec:thesis}

Memory should be formalized as time-delayed causal dependence among the variables (observed or latent) of a temporal SCM; an external store is just a variable with identity dynamics and gated write/read edges, so internal and external memory are the same object in the graph. The goal is \emph{trustworthy memory}: the stored representation should correspond to the true memory-relevant latent variables and their write/hold/read structure, up to the indeterminacies allowed by the model class --- value correspondence, structure correspondence, and selection soundness (D\ref{def:trust}). Improved reliability and efficiency are byproducts, not the target. This graph is a generating mechanism supporting $\Do(\cdot)$-statements, not a knowledge graph of asserted relations.

\paragraph{Division of labor between CD and CRL (my understanding, for checking).}
Layer~1 is a causal-discovery problem: the relevant variables $s_t = z_t$ are observed, and the task is to recover the temporal structure over them and use it to define the memory mask $F_t$. Layer~2 is a causal-representation-learning problem: the memory variables are latent inside $x = g(z)$, so the central issue is whether $\hat z$ corresponds to the true memory latents $z$, up to the allowed indeterminacy, rather than merely being predictive; only then can the recovered memory structure be trusted. \checkY{is this the right role distinction between CD and CRL in this project?}

\section{Formal setup}\label{sec:setup}

Let $z_t = (z_{t,1},\dots,z_{t,n}) \in \mathbb{R}^n$ evolve over $t = 1,\dots,T$ within episodes drawn i.i.d., with unrolled DAG $G$ over $V = \{z_{t,i}\}$ and assignments
\[
z_{t,i} \;=\; f_i\big(\Pa(z_{t,i}),\, \varepsilon_{t,i}\big),
\qquad \Pa(z_{t,i}) \subseteq \{z_{t-\tau, j} : 0 \le \tau \le L\}.
\]

\begin{assumption}\label{a:scm}
The process is a temporal SCM as above with maximum lag $L$ and acyclic instantaneous ($\tau=0$) dependencies.
\end{assumption}

\begin{assumption}\label{a:gated}
(Gated stationarity.) $G$ and $\{f_i\}$ are time-invariant; time-variation enters only through a regime process $u_t \in \mathcal{U}$ (e.g., $\mathsf{write}_j$, $\mathsf{hold}$, $\mathsf{read}_j$) gating edge activations: each edge $e$ carries $\alpha_e(u_t) \in \{0,1\}$, and $f_i$ may depend on $u_t$. \checkY{Q1: this, or a regime-free nonstationary-transition formulation?}
\end{assumption}

\paragraph{Observation models.} Layer 1 observes the state directly, $s_t = z_t$. Layer 2 observes $x_t = g(z_t)$ with $g$ unknown and injective; the intended instance is an agent's internal state, which carries its memory. The harder variant, where memory and cue do not generate observations during holds, turns identification into a filtering problem and is deferred to the Layer-2 note.

\paragraph{Working assumptions (for the population statements below).} Noises are mutually independent across components and time, with regime-dependent distributions allowed; regime labels $u_t$ are observed (known by construction in synthetic settings); Markov and faithfulness hold for $(G,P)$ --- near-deterministic holds do not violate faithfulness of the true model, but they do destroy the power of tests that rely on it, so population and estimation claims are kept separate; there is no selection on the data --- false by construction for goal-filtered agent corpora, which is why D\ref{def:trust} carries certificate (iii); and data come from a fixed behavior policy $\pi$, so all recovered structure is relative to $P_\pi$. \checkY{are these the right working assumptions, or should selection, policy, or regimes be modeled differently from the start?}

\paragraph{The write-hold-read motif (unit of memory).}
Fix a cue $c$, a memory latent $m$, a readout $y$, and distractors $d$ with full-rank stationary dynamics; write at $t_0$, read at $t_1 = t_0 + \Delta$:
\[
\underbrace{m_{t_0} = w(c_{t_0}, \varepsilon)}_{\text{write, } u_{t_0} = \mathsf{write}}
\qquad
\underbrace{m_t = m_{t-1} + \sigma\,\varepsilon_t \ \ (t_0 < t < t_1)}_{\text{hold}}
\qquad
\underbrace{y_{t_1} = r(m_{t_1}, d_{t_1}, \varepsilon)}_{\text{read, } u_{t_1} = \mathsf{read}}
\]
The cue varies across episodes; the load-$k$ variant runs $k$ items, simultaneous or staggered. Two knobs organize everything: hold noise $\sigma \ge 0$ and delay $\Delta$. Per our meeting, $T$ is not a theoretical bound; the estimator's window $W$ is an engineering threshold to sweep.

\section{Definitions I want checked}\label{sec:defs}

\begin{definitionx}[Memory carrier]\label{def:carrier}
The process $(m_s)_{t_0 \le s \le t_1}$ is a \emph{memory carrier} for $(c_{t_0}, y_{t_1})$ if
(i) $c_{t_0} \nindep y_{t_1}$ under $P_\pi$ with $\Delta \ge \Delta_{\min}$, and
(ii) for every $s \in (t_0, t_1]$ and constant $\tilde m$, $c_{t_0} \indep y_{t_1}$ under $P_\pi^{\Do(m_s := \tilde m)}$.
Graphically, in the causally sufficient, no-selection case, the intended reading is that every path from $c_{t_0}$ to $y_{t_1}$ is mediated by the persistent process $(m_s)$. The definition is deliberately interventional: association at a lag is exactly what selection can fake.
\end{definitionx}

\begin{definitionx}[Causal frontier / memory mask]\label{def:frontier}
With $\past$ the nodes at times $\le t$, $Y \subseteq \future$ the task variables in a horizon window, and $\An^*(Y) = \An(Y) \cup Y$:
\[
F_t(Y) \;=\; \big\{\, v \in \past \;:\; \exists\, w \in \future,\ v \to w \in G,\ w \in \An^*(Y) \,\big\}.
\]
\end{definitionx}

\begin{lemma}[$F_t$ is the unique minimal sufficient memory]\label{lem:frontier}
Under A\ref{a:scm} and the Markov property, \emph{(i)} $Y \indep \past \setminus F_t \,\big|\, F_t$. Under faithfulness in addition, \emph{(ii)} every $S \subseteq \past$ with $Y \indep \past \setminus S \mid S$ satisfies $F_t \subseteq S$.
\end{lemma}

\noindent A short proof is drafted in my working file; I will include it once the statement itself is the right target. Consequence, if correct: $F_t$ is the population-level object for ``what should be retained for planning,'' since $\mathbb{E}[\phi(Y) \mid \past] = \mathbb{E}[\phi(Y) \mid F_t]$; estimating it in memory regimes is then the Layer-1/Layer-2 problem. \checkY{is $F_t$ the right formal object for ``what deserves storage''?}

\begin{definitionx}[Trustworthy memory]\label{def:trust}
An estimated system ($\hat z$, $\hat G$, write/read maps) is \emph{trustworthy} on a memory-relevant index set $M$ if:
\emph{(i) value correspondence}: $\hat z_{\rho(i)} = h_i(z_i)$ for all $i \in M$, for some permutation $\rho$ and component-wise invertible $h_i$; where this is provably impossible (simultaneously frozen items admit an arbitrary invertible mixing mid-hold), the certificate relaxes to block level;
\emph{(ii) structure correspondence}: the write/hold/read edges of $\hat G$ match those of $G$ on $M$;
\emph{(iii) selection soundness}: on data whose long-lag dependence arises from selection alone, the system reports \emph{no carrier}.
The intended payoff is that interventions on $\hat m$ can be read as interventions on the true carrier $m$, and that retention can shrink from the full history to $F_t$.
\end{definitionx}
