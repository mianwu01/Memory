Structural causal models

A graph that answers "what if", not just "what co-occurs"

A structural causal model is a set of variables, a DAG G over them, and one assignment per variable, Vi = fi(Pa(Vi), εi), where the parents Pa(Vi) are the nodes with edges pointing into Vi — its direct causes — and the noises are mutually independent. It entails a distribution P — but it is more than a distribution: the intervention do(Vi := v) deletes that variable's assignment, fixes it to v, and leaves every other mechanism untouched — graphically, it cuts all edges into the variable.

That is why an edge here is a claim about what happens under manipulation, not about correlation. The memory-carrier definition is deliberately stated with do(·) for exactly this reason: it builds the confabulation test into the concept itself.

Markov and faithfulness — and why the project needs both directions

Two bridge assumptions connect graph and distribution, and you must know which claim uses which, because Yujia will ask.

Markov

d-separation in G ⟹ independence in P. The sufficiency half of the frontier lemma (the frontier screens off the rest of the past) uses only this.

Faithfulness

independence in P ⟹ d-separation in G — no accidental cancellations manufacture independences. The minimality half (every separating set contains the frontier) needs this, because it argues from an active path to an actual dependence.

Keep the population / estimation split sharp: faithfulness can hold exactly for the true model while conditional-independence tests still fail in practice. That gap is precisely what near-deterministic holds do — and it is the Layer-1 shadow of the whole identifiability story.

Temporal SCMs

The unrolled graph

Index variables by time. The unrolled graph has one node per variable per timestep, with edges from lagged parents and optionally instantaneous edges inside a slice. This project works on the unrolled graph — not the time-collapsed summary graph — because memory is precisely a claim about which timesteps depend on which.

Layer 1's toolbox

Causal discovery in practice

All four algorithms take trajectories of observed variables and return a graph over time-indexed nodes.

PC · PC-stable

Test independence for growing conditioning sets, delete accepted edges, orient v-structures. In time series the arrow of time orients all lagged edges for free.

PCMCI⁺

PC engineered for autocorrelated series: a condition-selection stage finds each variable's lagged parents so the final tests keep power. The Layer-1 workhorse in E0.

CD-NOD

Adds the context index — for us, the regime ut — as an observed node. Given gated stationarity, this is the most natural fit of the three; say so if asked.

DYNOTEARS

Score-based: continuous optimization of adjacency matrices under an acyclicity penalty. Fast, but its guarantees lean on parametric assumptions — treat it as a cross-check.

What matters for memory is what each assumption failure looks like in the output, because the first experiment is designed to elicit exactly these signatures:

  • Frozen-variable regime (F1). When mt ≈ mt−1, tests conditioning on its past value can't tell it from a constant. Precisely the variables doing the memorizing are the ones discovery sees worst — mid-hold. Recovery concentrates at write/read boundaries, where events inject variance. That asymmetry is Prediction P1.
  • Latent confounder (F4). Clusters of spurious edges among the confounded variables.
  • Selection (F2). Confident edges between jointly-selected variables, with no carrier in the true graph.

The heart of the background · read twice

Causal representation learning and identifiability

Suppose observations are generated as x = g(z) with g unknown and invertible, and all you are given is P(x). Then for any invertible map h, the alternative model ẑ = h(z), ĝ = g ∘ h−1 produces exactly the same P(x). Recovering z is not merely hard — without further structure it is meaningless: infinitely many latent descriptions are observationally indistinguishable.

Identifiability classes, in decreasing strength

A

Component-wise — the gold standard

ẑ equals z up to a permutation of coordinates and an invertible scalar per coordinate. This is what "the agent memorized the true value" means formally — certificate (i) of trustworthy memory.

B

Block-wise

A known group of coordinates is recovered up to an invertible transform of the whole block: you know where the information lives, but not the coordinates within.

C

Set-level

Latents are recovered as sets, with guarantees about membership rather than individual coordinates — the natural target where component-wise is provably impossible, and the honest fallback for frozen memory blocks mid-hold.

Think of the indeterminacy group — the transformations h that map solutions to solutions. Identification shrinks it. Memory holds do the opposite: freezing k latents enlarges the group by every invertible mixing of the frozen block. The three mechanisms in the formulation are three ways of shrinking it back down.

The two classical routes to identification

Route 1 · variation

If the latent prior changes with an observed auxiliary variable u — environment index, regime, timestamp — and the conditionals vary enough, the changes pin down the coordinates. Identification is purchased with variation.

Route 2 · structure

Yujia's own line: if the mixing or latent graph is sparse and structurally diverse, identification follows from structure alone — even in the Gaussian case where Route 1 is hopeless. Structurally identical implies indistinguishable.

That single slogan explains the whole memory difficulty: a frozen coordinate contributes no variation (holds are poison), while a write/read event is a large, localized variation (events are medicine). And two simultaneously frozen items are structurally identical during the hold — which is the capacity limit, in one line.

How recovery is scored

MCC

Best one-to-one matching of absolute correlations between estimated and true latents (Hungarian assignment), averaged. Component-wise identification predicts MCC → 1; a set-identifiable frozen block predicts high block-MCC with low component-wise MCC — and that gap is itself evidence.

Edge F₁ · SHD

Graph recovery against the true unrolled adjacency, always split by edge type (write / hold / read) — because the whole point is that recovery is not uniform across the motif.

The one confound that can fake memory

Selection

Conditioning on a collider creates dependence between its causes. If a selection variable S is computed from both cue and readout and the dataset keeps only S=1 episodes, then inside the dataset the cue and readout are dependent even when no path connects them in the true graph. The dependence has no carrier, survives at any lag, and looks exactly like memory to any method that must explain dependence generatively.

This is first-order, not a corner case: agent data is selected on by construction. Imitation keeps successful episodes (selection on return); RLHF filters on preference; and a NeurIPS 2024 result shows subgoal structure in demonstrations is a selection on state–action pairs, formally. So the no-selection assumption is false for precisely the corpora agents are trained on — which is why trustworthy memory carries a certificate that can report "dependence present, carrier absent, cause: selection."
