01 / 04 The thesis

Memory is identifiable causal structure in the process that makes the data.

An agent should not store every signal at every moment. It should store what corresponds to the truthful process that generates its observations — and read the past through that process's dependency structure.

Mian (Nothern) Wu prepared for verification with Yujia Zheng Formulation v0.1 · July 2026

The unit of memory

The write–hold–read motif

Everything in the program is analyzed on one small structure: a cue is written into a memory latent, the latent is held across a delay, then read into a downstream response while distractors run in parallel. The teal path is the carrier.

In one paragraph

What the project claims

Memory is time-delayed dependency structure inside the true data-generating process — not a separate external module. An external store is formally just a variable with identity dynamics and gated write/read edges, so the internal/external distinction dissolves at the level of the graph. A memory system is trustworthy exactly when its stored values and its write/read structure correspond, up to allowed indeterminacies, to that process.

The primary contribution is correctness of what is memorized. Reliability and efficiency follow as byproducts — they are not the headline. Getting there needs two things nothing in the memory-agent literature supplies: a guarantee that a learned representation ẑ corresponds to the true hidden process z, and a test that separates genuine storage from dependence that mere selection can fake.

Adjacent formalisms give sufficiency or usefulness. None gives correspondence to the true generating process — which is exactly what identifiability adds, and the entire reason the project exists.

The program

Two layers

Both layers analyze the same object — the motif above — at different depths of guarantee.

Layer 1 · discovery-as-masking

Recover the structure

Run temporal causal discovery over observed state variables. Use the recovered cross-time graph as a mask for what to memorize and as the conditional set for planning. No latent-value recovery — this de-risks the program.

Layer 2 · representation learning

Recover the values

Temporal causal representation learning with identifiability guarantees: what the agent stores must equal the true latent value, not merely a predictive embedding of it. First reconstruct the truthful latent states, then recover their dependencies.

Definition D3

Trustworthy memory

An estimated system — latents ẑ, graph Ĝ, write/read maps — is trustworthy on a memory-relevant index set when three certificates hold. Each is tied to an operational test, so "trustworthy" never floats free.

i

Value correspondence

Stored latents equal the true ones up to permutation and per-coordinate invertible maps (component-wise identifiability), relaxing honestly to block-wise on frozen subspaces where component-wise is provably impossible. measured by MCC.

ii

Structure correspondence

The write, hold, and read edges of Ĝ match those of the true graph. measured by edge F₁ and SHD, split by edge type.

iii

Selection soundness

On data whose long-lag dependence arises from selection alone, the system reports no carrier rather than inventing a memory edge. measured by false-positive rate on selection-only data.

Byproduct · trustworthiness in use

With value + structure correspondence, intervening on m̂ intervenes on the true m: memory editing inherits specificity, recall becomes auditable against an identified carrier, and confabulation — recall without a carrier — becomes detectable.

Byproduct · efficiency

Retaining only the causal frontier Ft instead of the whole history shrinks the memory budget from O(nT) to |Ft| with no task-relevant loss, and planning conditions on the frontier alone.

Positioning

Why this is not the memory-agent literature

Predictive-sufficiency formalisms — POMDP belief states, predictive state representations, computational-mechanics causal states — already define memory as a minimal sufficient statistic of history. World models learn useful latents. Agent-memory systems engineer storage and retrieval. Every one of them is missing the same half: no guarantee that the learned statistic corresponds to the true generating process.

That correspondence is what identifiability supplies, and it is the one thing that makes stored content editable with specificity, auditable, and falsifiable as confabulation. The differentiator is not a benchmark number — it is interventional access to identified carriers.
