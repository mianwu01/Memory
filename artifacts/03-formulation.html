Formal setup

The temporal SCM and its three observation models

Latent state zt ∈ ℝn evolves over an episode with structural assignments zt,i = fi(Pa(zt,i), εt,i), parents drawn from lags 0…L, the instantaneous part acyclic, noises mutually independent. Nonstationarity enters only through an observed regime process that gates edge activations — so discrete events (a write, a read) live inside a stationary model.

O1 · Layer 1

The latents are the observations, st = zt. No mixing to undo; discovery applies directly.

O2a · internal state

xt = g(zt), g unknown but injective — an agent's own hidden state, which necessarily carries m. The well-posed first target: Program A.

O2b · environmental

During holds, memory and cue are excluded from what generates xt. Per-step inversion is impossible in principle — the ambitious extension, Program B.

A1 – A9

The assumptions, annotated for defense

Each says what it means, why it is there, and — where it matters — the pushback to expect.

A1

Temporal SCM, max lag L

Time-indexed SCM, bounded lags, acyclic instantaneous edges. Long-range influence comes precisely through bounded-lag edges — the carrier chain — which is the point of the motif.

A2

Gated stationarity

Mechanisms are time-invariant; events enter as an observed regime ut gating edges. Simultaneously CD-NOD's input format and the auxiliary variable Conjecture 1 leans on. Whether to keep it is Q1.

A3

Independent noises

Mutual independence across components and time, regime-dependent distributions allowed. That "allowed" clause is load-bearing: mechanism (c) needs the freedom to make hold noise non-Gaussian.

A4

Observation models

O1 / O2a / O2b as above. O2a is the natural model for analyzing a trained agent's internals; O2b gets its own impossibility-flavored observation rather than being assumed away.

A5

Regimes observed or estimable

Event times known in synthetic data, estimable by change-point detection otherwise. A5 gives event times, not content or structure — so it is not circular.

A6

Markov & faithfulness

With the caveat stated inside: near-deterministic holds break test power, not the true model's faithfulness. This is what lets Lemma 1 (population) and failure mode F1 (estimation) coexist.

A7

No selection, unless modeled

Explicitly false by construction for goal-filtered agent corpora — the reason the selection section exists. Stated as a feature, not softened.

A8

Fixed policy; structure is Pπ-relative

The recovered graph depends on the behavior policy, since the policy reads memory to act. Whether invariance belongs in the definition is Q7.

A9

Causal sufficiency (Layer 1)

No latent confounders among observed state variables; relaxable to FCI-class methods at the cost of weaker output. Named as failure mode F4.

D1 · the memory carrier

Why the definition is interventional

Definition D1 — memory carrier

The process (ms) is a memory carrier for (ct₀, yt₁) if the long-lag dependence exists and cutting the chain at any hold step by do(ms := m̃) destroys it — equivalently, every active path from cue to readout passes through the carrier.

Two design choices to be able to justify. First, interventional rather than associational: association at a lag is exactly what selection can fake, and do(·) is the thing selection cannot fake — so the definition builds the confabulation test into the concept. Second, quantified over every cross-section: memory is carried continuously through the hold, so cutting anywhere must sever it. That makes "the carrier" a process, not a single node — the property the gluing step later exploits.

Lemma 1 · the causal frontier

The unique minimum memory

The one fully proved result — the anchor of Layer 1. Informally: at any moment there is a unique smallest set of past variables that carries everything the future task needs, and it has a clean graph description.

Ft(Y) = { v at time ≤ t : v has a child w at time > t with w ∈ An*(Y) }

In words: the past variables that are, right now, one edge away from mattering to the future of the task. Not everything correlated with the future, not all ancestors of Y — the last past layer of the relevant part of the graph.

The proof, as a story

Two halves, using the two bridge assumptions separately — itself worth saying, because it shows the proof knows what it is spending.

Sufficiency · Markov only

Take any past-to-future path. Edges never point backward in time, so the path crosses the boundary along some v→w, arrowhead on the future node w. Once in the future it can never turn around: turning back makes a future collider, and a collider only opens if it or a descendant is conditioned — but all descendants of future nodes are future, and the conditioning set is entirely past. So the path marches directedly forward to y, making w an ancestor of Y and v ∈ Ft, a non-collider on the path. Condition on the frontier and every such path dies.

Minimality · faithfulness

Take any f ∈ Ft with boundary edge f→w and extend to a directed path f→w→…→y. Every node after f is future, hence outside any past conditioning set; a directed path has no colliders; so if f is not conditioned on, the path is active, and faithfulness upgrades "active" to "actually dependent." Any separating set that omits f fails — so every separating set contains all of the frontier.

Combined: the frontier is not just a minimal separator, it is the unique minimum one — the intersection of all valid memories, and itself valid.

The corollaries, and what each is for

Planning

𝔼[φ(Y) | past] = 𝔼[φ(Y) | Ft] — the "conditional set for planning" made exact.

Online recursion

Ft+1 ⊆ Ft ∪ Vt+1: add the new slice, retire nodes whose relevant children have passed. That recursion is an online memory rule with budget |Ft|.

Task-conditioning

Ft depends on Y and the horizon; different tasks induce different memories — the bridge to generalist-to-specialist.

Scope

All of this is about the true graph. Whether the frontier is estimable in memory regimes is what Layer 1 and the first experiment interrogate. Is it the right formal target? — Q3.

Layer 2 · the identification story

Holds enlarge the symmetry group

Observation 1. Take k items written together, frozen (σ=0), read together through a shared readout. Then for any invertible R on the block, the substitution m ↦ R(m), w ↦ R∘w, r ↦ r∘R−1 changes nothing observable — and the hold dynamics survive, because a constant is still a constant after R. Mid-hold, the block is set-identifiable at best. The standard escapes are closed by the regime itself: at σ=0 the transition is a point mass, so IDOL's smooth-density assumption fails outright, and as σ→0 the variability directions tied to m collapse.

The three mechanisms that shrink the group back

Each kills the rotation by a different argument, and each maps to a dedicated experimental arm.

a

Structural diversity of reads

Give each item its own read child. Then r∘R−1 densifies the read Jacobian unless R is a permutation-scaling — a sparsity-seeking estimator forces component-wise recovery. shared-vs-per-item arm.

b

Temporal diversity — staggering

Under the gate, (Rm)j may only change at item j's own events; distinct write times force R diagonal, else an item would jump when another is written. simultaneous-vs-staggered arm.

c

Non-Gaussian hold noise

With σ>0, transformed innovations must stay independent. Isotropic Gaussian lets every orthogonal R through (the classical failure); non-Gaussian admits only permutation-scalings — the hold noise runs ICA inside the block for free. Gaussian-vs-Laplace arm · P4.

Conjecture 1, decomposed by risk

C1a · boundary

At write/read times, memory components are component-wise identifiable — events are large localized changes, and change is Route-1's currency. low risk

C1b · mid-hold

Within a hold, the frozen block is recoverable as a set, by the set-identifiability machinery applied within regimes. low–med risk

C1c · gluing

Boundary labels transport through the hold because the transition is diagonal by construction — upgrading set-level to component-wise whenever (a), (b) or (c) holds. where a proof most plausibly breaks

Q2. Is the regime-change + set-identifiability + gluing strategy viable, or is there a cleaner route through the nonparametric-concepts machinery? The gluing step is handed to Yujia with the alternative route pre-named.

Conjecture 2 · capacity is distinguishability

Working-memory capacity limits, in this theory, are not storage limits but identification limits. Simultaneously written, jointly read, Gaussian-held items are indistinguishable within their block no matter how much capacity the substrate has; staggering or structural diversity restores distinguishability item by item.

Observation 2 · identifying memory requires memory

Under O2b the cue is visible only at write and m never generates observations during the hold, so mid-hold observations are independent of the memory content: any encoder whose window fails to reach back to the write event outputs a statistic with I(T; ms) = 0 — chance by construction. The estimator must itself carry information over span ≥ Δ. The neuroscience echo: activity-silent working memory is exactly the O2b regime, a carrier invisible to per-step measurement.

P1 – P4 · pre-registered & falsifiable

The predictions

P1

Time-localized recovery

Write/read boundaries are recovered markedly better than mid-hold structure, degrading as σ→0 and Δ grows — at both layers.

P2

Selection fakes a memory edge

On the selection-only construction, pipelines without the gate assert a spurious long-lag edge; with the gate, dependence is correctly attributed to selection.

P3

Capacity is block-wise

Simultaneous k-item recovery is block-wise, not component-wise (within-block MCC near chance under Gaussian noise + shared readout); staggering or distinct read children restores it.

P4

Laplace beats Gaussian

With simultaneous events and a shared readout, Laplace hold noise yields higher within-block MCC than Gaussian at matched σ — mechanism (c).

The experiments · run only after sign-off

E0 and E1

E0 · discovery on the observed motif

CPU-only, days. No mixing, no VAE — any failure is attributable to the memory regime itself. Sweep Δ, σ, k, simultaneous vs. staggered, window W. Pass: read-edge F₁ > 0.7 at (Δ,k,σ)=(10,1,0.01). Deliverable regardless: the recovery-frontier heatmap.

E1 · CRL with unknown mixing

1 GPU, 2–3 weeks. Adds a 3-layer MLP g, O2a and O2b arms, an IDOL-style sequential VAE plus an event-gated variant. Dedicated theory-testing arms: encoder context ≥ Δ vs. < Δ (Observation 2), Gaussian vs. Laplace (mechanism c). Pass: MCC(m) > 0.8 and read-edge F₁ > 0.7 under O2a.

Both experiments are informative under any outcome: mild degradation validates the premise; severe degradation makes event-gated estimation the methods contribution. And none of it runs before sign-off.
