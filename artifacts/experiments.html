Task 1 — discovered memory selection in MemoryArena

We registered CausalMemorySystem into MemoryArena at runtime (their repo stays byte-identical — it ships no licence, so we do not fork it) and ran it through the real HTTP memory interface on 60 travel episodes / 401 rounds. The learned graph is exported from cross-episode travel data; the pure arm additionally removes query-name seeding, so it has no person-name oracle.

What the ablation proves. causal-noG is our system with the causal graph switched off: same slot parsing, same hold rule, but it keeps every slot. It reaches 100% answerable — and costs 2487 tokens. Task 2 — recovering the hidden driver of a published attack

Carrier: MINJA (NeurIPS 2025), a memory-injection attack. We reuse its released data and payload unmodified — the poison instructs the agent to shift its answer by +4 in ASCII when it sees the word "food", so an anomalous action is self-labelling (an answer in E–H). Our only additions are logging and a clean pre-injection probe phase.

Original P3 auditing status: SUPPORTED_WITH_IDENTIFICATION_BOUNDARIES. This is a descriptive synthesis of frozen evidence, not a newly invented confirmatory PASS. The later online-mitigation protocols retain their independent pass=false judgements.

The fixed three-seed replication is positive but variable. Across 243 rounds, the held-out test ASR is 8/36 = 0.222. More decisively, the attack fires on 22/76 = 0.289 rounds where no instruction is visible and a poisoned record is retrieved, versus 0/77 without poison retrieval. The per-seed decisive rates are 0.324, 0.194, and 0.500: 2/3 clear the criterion fixed before execution (>0.20). The pathway replicates, but seed 0's 0.500 test ASR is not a stable point estimate.

How to read it: the note-free / poison-read cell is the discriminating one. Across all seeds attacks succeed in 28.9% of those rounds; without poison retrieval, note-free attacks are 0/77. The visible-note cells remain useful as an attack-mechanism check, but they are not used to establish hidden-memory causation.

Which write drove the later actions?

Runtime provenance traces each retrieved record to its write round. In seed 0, the strongest driver is t=14, an ancestor of 10 anomalous actions; the next two writes drive 9 and 8 actions. This is the structural answer a per-record anomaly score cannot provide.

Identification boundary. MINJA's poison_retr variable is constructed from is_poison, so this experiment recovers the structure of an oracle-tagged read channel; it does not by itself show blind record identification. The retrieve→act relation is also within-round, so lag-0 direction is allowed only because the instrumented runtime records retrieval before action. This is not direction learned from observational simultaneity with no assumption. Seed 0's trigger-specific coefficients are 0.0202 (p=0.8479) and 0.7729 (p=2.932e-06).

The method itself: regime-conditioned discovery

Everything above uses a graph. This is the estimator that finds one when the edge is gated — switched on and off by a regime rather than always present.

A gated edge is multiplicative: the coefficient on the parent depends on the regime. Adding the regime as one more node — the standard move — only shifts the mean, so it cannot express that, and it fails. Conditioning on the regime recovers the edge:

Read edges recovered, out of 2. The middle column is the honest control: it is the obvious thing to try, it is what we shipped before, and it recovers nothing. Our estimator also flags each recovered edge as gated, which is what the defence below consumes.

Against the competitor: MemAudit

MemAudit (arXiv 2605.23723) is the nearest prior work and released no code, so we reimplemented both halves from the paper to make the comparison concrete.

MemAudit componentAUC precision@k
CMIS — per-record counterfactual influence 0.6700.758
Consistency graph — structural anomaly 0.0670.848

We do not claim a detection win. CMIS remains a competitive per-record baseline (its precision@k is shown above). The difference is structural, not a score: MemAudit scores records one at a time against a static semantic graph, so it cannot say which earlier round's write drives a later action, and its graph cannot be handed back to the memory system as a selection policy. Across three seeds, CMIS macro AUC is 0.866 and macro precision@k is 0.874; it is a strong detector. Our graph does both selection and temporal auditing — that dual use is the claim.

Substitution to disclose: their DeBERTa-v3 NLI relatedness is replaced by lexical overlap here, because this project is CPU-only. That mainly weakens their second row.

What we are not claiming

  • P3-A's SUPPORTED label is an evidence classification for Yujia's original hidden-driver auditing question, not a retrospective confirmatory PASS. P3-B's two frozen online pass=false results remain unchanged.
  • The 60-episode P2 result is answerability at cost, not task success. The official five-episode PS/SPS/SR comparison is separate and still has wide episode-level uncertainty.
  • The 1.000/1.000 learned arm still seeds selection with people named in the query. The pure-discovery arm removes that oracle and is positive against BM25, but leaves a real gap.
  • Travel queries name many dependencies, so this environment does not establish that causal discovery is necessary in general.
  • Ordered lag-0 orientation uses measured runtime order. It is not assumption-free orientation from a static observational table.
  • MINJA's poison_retr is oracle-derived. Fully label-free record recovery is shown only in the AgentPoison carrier: 1/2 records directly and 2/2 after frozen cluster expansion, with the disclosed development/calibration overlap.
  • Conventional blind PCMCI misses the P3 edge; that negative result remains part of the record even though Regime-GRACE recovers it.
  • The trigger-rarity sweep referenced in the working notes was run against an offline stand-in answerer, not a real LLM — it is a synthetic diagnostic, not a measurement.
  • MemAudit released no code and its NLI component is approximated with lexical overlap. We do not claim to beat it at poison detection; the contribution is temporal ancestry and reuse of the graph for gating.
  • The ancestry+regime replay covers 95.3% of saved anomalous rounds, but the real held-out online gate lowers micro ASR only from 6/36 to 5/36 and improves only 1/3 seeds. It fails the frozen online acceptance rule; replay coverage is not a measured prevention rate.
