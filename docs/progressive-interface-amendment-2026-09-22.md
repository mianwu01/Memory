v1首个子问题出现原生12轮结束后仍有tool_calls、没有答案的情况。该预算终止
不是正常stop，不能当合格writer。停止前两题接口调试进程，保留v1所有原始
响应、session及请求意图；中断的未返回请求单列，可能已计费。

v2保留同一模型、thinking、检索、问题和12轮工具预算。若仍有工具请求，先
执行其工具（原生循环已执行），随后以相同对话补一次无工具收束：仅根据
已有证据回答，证据不足返回UNKNOWN。不含gold/额外资料，不重新搜题。
原生预算命中次数单列，不能因收束stop隐藏。若finalization仍截断，资格失败。
使用独立dev_v2结果目录并共享v1 API ledger，按job与完整请求哈希复用成功响应。
修复产生不同后继memory的请求不得冒充旧调用的独立重复。

原生source无修改；这是公开说明的执行接口适配。v1不是新有效实验行。
