# Query 与原生记忆依赖复核

这是采集后的输入审查，没有新增模型调用，没有修改冻结任务或评分。
逐题原文与检查保存在
`results/development/progressive_search/query_dependency_review.json`。

固定10题的子问题和最终问题均来自原始数据集。它们没有URL，也没有官方
完整答案的连续归一字面；这一检查不排除别名、部分线索或间接泄漏。最终
问题本身提供了丰富条件，许多子问题又重复其中的条件。任务分解和这些
线索是外部给定的，不能称为PCMCI发现的结构。

实际的记忆使用是：每次子问题之前读取全部已有LongContextMemorySystem
文本，完成工具交互后追加预测答案与trace。67次真实写入形成57对相邻转移；
PCMCI边界截取后的有效候选样本为47。输入链与原文哈希可以独立检查。
这证明原生跨轮记忆接口被使用，不证明每条历史对最终答案都必要。

选择器只用最终query、文本投影、历史entry与已拟合图；不消费gold答案、
gold文档集合或oracle依赖parser。可是query种子topic和BM25本身就提供
关联筛选，历史最终答案还可能直接复用。因此设置topic_only、complete、
BM25、query_only及三种历史答案复用对照；同一输入共享响应。

目前discovered与空图topic_only在10/10题产生完全相同请求。四条自环
不会扩张query种子的祖先集合，所以发现边没有参与改变这些读取输入。
即使某个选读条件得分优于full，也不能归因于发现的时序结构。错图失败
同样不能推翻这一输入级证据。

本场景落实了原生读写、任务时间步、实际转移数和可核对结果，但尚未落实
有意义的语义记忆机制，更没有通过独立结构作用验收。
