# E0 v0 结果:合成 write–hold–read SCM 上的 Layer-1 发现(2026-08-20)

> 设计来源:`causal_memory_formulation.tex` §exp E0(v0 缩减版);脚本 `code/e0_synth.py`。
> CPU-only。方法:(a) **blind PCMCI+**(tigramite ParCorr,忽略 regime u_t);
> (b) **regime-aware 回归**(按 u_t 分子样本的 OLS + BH-FDR,CD-NOD 的穷人版)。
> v0 缩减:线性高斯、k=1、n=8(c, m, y, d1..d5)、每配置 200 episode 连成单序列;
> 扫 Δ ∈ {5,10,20} × σ_hold ∈ {0, 0.01, 0.1}。边按类型评:write(c→m)/ hold(m→m)/
> read(m→y, d1→y)/ distractor(VAR(1) 8 条)。

## 2. 三条读数

**R1 —— 门控稀释使 blind 发现在 read 边上全线失明。**
read 边只在每 episode 的 1 个时间步激活(占样本 1/(Δ+10)),混入全体样本后
边际信号低于检验阈:blind PCMCI+ 九个配置**全部漏掉 m→y 与 d1→y**。
这是 A2(门控平稳性)的经验版本:**u_t 作为 auxiliary variable 不是可选项,是必需品**
——正是 Yujia 7 月会点名的表述,现在有了数字。

**R2 —— 冻结保持的失效是非单调的,且精确落在预测处。**
regime-aware 方法在 σ=0 与 σ=0.1 全对,却在 **σ=0.01 恒漏 m→y**(三个 Δ 一致):
保持段近确定( m_t ≈ m_{t-1} )使 read 时刻 (m,lag0) 与 (m,lag1) 近共线,
标准误膨胀、检验失效;σ=0 时精确共线反而由伪逆的最小范数解侥幸通过。
这确认并**细化**了 formulation.tex 的 F1 预测(原预测"hold 边恢复差";
实际 hold 边无恙,**被杀死的是 read 边的检出**,且随 σ 非单调)。
v1 修法明确:共线感知检验 / 只用单侧滞后 / 以写入锚定的回归(y 对 m_{t_w})。

**R3 —— 边错误按前沿引理传导为"丢掉记忆本体"。**
真前沿 F_t = {m, d1, d2}(修正门控语义后)。凡 m→y 检出,F̂_t 与真前沿完全一致
(P=R=1.0);凡 σ=0.01 漏检,F̂_t 恰好**丢掉 m**(R=0.667)——按学得图做保留的系统,
会在最需要记忆的时刻把记忆项丢弃。边级错误 → 保留策略错误的传导链,首次被演示。

**判据裁定**:tex 预注册的通过标准(read-edge F1 > 0.7 @ (Δ,k,σ)=(10,1,0.01))
在 v0 两方法下均**未达标**(regime 0.5 / blind 0.0)——不是坏消息,而是 E0 存在的意义:
它把"哪里会断"从预测变成了测量,并给出了 v1 的修复清单。
Δ 不影响恢复(边都是局部的,长程性由链承载)——符合 L1(m 可观测)的预期。

## 3. 限制与 v1 待办

1. 线性高斯、k=1、单一种子;v1 加 MLP 机制、k∈{2,4}、多种子置信区间;
2. "regime-aware 回归"是 CD-NOD 的代理,v1 换正式 CD-NOD / 带 regime 指示的 PCMCI+,
   以及 GRACE(它在此获得第一个运行理由:对照它的 gating 能否自动发现 u_t 的作用);
3. σ=0.01 失效的修复实验(共线感知 / 写锚定)是 v1 的第一项;
4. episode 边界拼接对 lag-1 检验有轻微污染(200 个边界 / 3000+ 样本),v1 用
   tigramite 多数据集模式消除。
