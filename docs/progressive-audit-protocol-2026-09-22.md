# 同一发现结构的来源干预与授权替代（测试前冻结）

全部固定case进入报告。仅full独立三次严格正确且无截断、writer完整者适用
“正常正确输出”审计；其余保留不适用理由，不换题。发现结构来自第三关的
同一fit，不再拟图、不用干预结果回头挑边。

外部权限场景：存储的历史记忆副本可被撤销信任，真实corpus工具返回才是
当前授权来源。这是预先声明的模拟撤销政策，不推断文档作者恶意或实际违法。
locator先按discovered规则找到候选记录，在这些记录中选BM25最高者作为
本次撤销/检查的记录。该选择是审计方法输出，不是已证明的问题源真值。
同时用complete规则/BM25第一名定位，作为不需要discovery的来源对照。
两者一致必须明确报告。被撤销记录读过的全部docid进入授权重取的排除表，
不让同一文档换标签后冒充新来源。

对适用case，以相同full memory reader作固定干预，每种三次独立读：
1. baseline：复用三次full结果，不再调用。
2. blocked：真正删除候选原生memory entry，保留其它记录/原时间戳。
3. changed：把该记录中的baseline repeat0答案替换为固定
   `Counterfactual Entity <case id>`（大小写不敏感，字边界匹配），保留关系
   描述，使该关系的指向改变；报告替换次数及预期反事实答案。若记录不含
   baseline答案，明确“没有决策信息替换”，不把换标签算成功、不挑新记录。
4. neutral：仅向同一记录末尾追加固定归档版本说明，不改变事实内容。
5. complete_blocked：同样删除complete/BM25选出的记录，检验图的增量。
6. authorized：用同一native搜索工具链、同一Flash thinking，从final question
   独立获取新证据；读取排除表之外的真实corpus文档。旧记忆全部撤销，最终
   只给新原生工具trace+predicted answer。最多12工具轮，必要时无工具收束。
   输出正确且存在实际非排除来源读取才算可执行授权替代的必要条件；另核对
   引用是否支持结论，不用source标签代替证据。
7. no_evidence：空memory，同reader；检查是否按规则UNKNOWN，区分模型已有
   知识/猜测与来源依赖。repeat0可复用第三关query-only，剩余独立重复。

每个case/重复内，完整请求相同则共享响应，绝不重复计作独立样本。变更没有
发生、阻断无效、模型拒绝反事实、neutral改变答案、授权来源不可得、UNKNOWN
失败均原样报告。原始被撤销记录的摘要可能在其它记录中冗余，因此删除一条
不等于彻底来源隔离；报告其它记录中原答案的残留次数。审计的证明范围限于
实际输入干预，不能据此宣称追踪了模型内部思想或完整信息流。

### 首次审计调用前：完整来源阻断的保守版本

额外执行source_blocked三次：找出读过撤销docid的所有写入，并沿实际原生
“后续writer读全部历史”的read provenance闭包，删除最早受影响写入及其
全部后继。该版本阻断了可追踪来源进入当前memory的路径，但可能严重过度
阻断，不能当最小causal set或图特有收益。保留原单记录blocked，用来区分
局部删除、冗余路径与真正保守来源隔离。相同空输入复用同repeat响应。
授权结果另外检查是否与禁止文档同URL/原文hash；字面答案是否存在于真实
返回文档只算支持性检查，不替代完整语义证据核对。
